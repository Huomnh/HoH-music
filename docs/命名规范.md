# HoH music 命名规范

## 对外名称

| 用途 | 统一值 | 规则 |
|---|---|---|
| 产品显示名 | `HoH music` | UI、窗口标题、文档正文固定使用此大小写 |
| Dart / Flutter 项目名 | `hoh_music` | pubspec、可执行文件、Dart package import 使用 snake_case |
| 应用标识 | `com.hohmusic.hohmusic` | 新平台工程统一使用；旧数据迁移不能直接删除 |
| 主题包 | `.hohtheme` | ZIP 容器，兼容导入旧版本主题包 |
| 音源脚本 | `.hohsource.js` | 普通 `.js` 仍可导入 |
| 调试环境变量 | `HOH_*` | 禁止新增旧前缀变量 |

## Dart 代码

- 类型使用 `PascalCase`，例如 `HoHMusicApp`、`OnlineTrackDownloadService`。
- 方法、变量和文件使用 `lowerCamelCase` / `snake_case.dart`。
- Provider 以职责结尾：`libraryProvider`、`sourceHostProvider`；控制器以
  `Controller` 结尾，服务以 `Service` 结尾。
- 不把产品名写进业务变量；产品名只出现在应用根组件、展示文案和平台元数据。
- 平台代码放在 `lib/platforms/<platform>/`，共享业务代码不直接依赖 Windows API。
- 新代码、产品 UI、测试资源名和脚本统一使用 HoH 命名；不要引入个人用户名作为产品标识。

## 兼容原则

- 改名只改变新安装的标识和显示，不删除旧版本用户数据。
- SharedPreferences、主题包和音源登记读取时保留旧键迁移；写入统一使用新命名。
- 内部 JS 沙箱协议使用 `hoh_*` / `__hoh*`，第三方 LX 音源的公开 API 名称保持不变。
