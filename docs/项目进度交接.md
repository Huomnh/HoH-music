# HoH music 项目进度与交接

> 音源启动策略：安装包程序目录的 `music音源` 会在启动时自动扫描并登记，默认启用第一个可用脚本；旧 `assets/sources` 不再加载。用户整理的 `music音源` 文件夹已保留。

> 启动扫描入口：`LibraryBootstrap._restore()` 在首帧后同步等待 `_warmSourceHost()`，先扫描并登记程序目录/工作区的 `music音源`，再初始化 `sourceHostProvider`；空的程序目录不会阻断工作区候选路径，旧 `assets/sources` 登记会迁移清理。

> 曲库清理：音源管理页的“清空本地索引”会清空登记路径、Drift `hoh_music` 本地曲目表和隐藏记录，但不删除音频文件；“清空在线播放记录”只清除 `library.online`。

> 外观清理：已移除全局程序字体选择器，主界面恢复系统默认字体；歌词专用字体设置仍保留。已移除“极光丝带”背景及其主题包资源，旧设置导入时回退到“液态流光”。

> 字体：`assets/fonts/KirakaraMaru_v1.1.ttf`（耀圆体）已作为 Flutter 内置字体随程序打包；主 UI 与播放页歌词默认使用 `KirakaraMaru`。用户导入字体功能仍写入应用数据目录，不覆盖内置字体。

> 版本入口：左侧设置区“播放设置”下方新增独立“版本说明”页面，显示当前版本和 GitHub 反馈地址；实现文件为 `lib/features/player/version_info_view.dart`。

## 本轮曲库来源边界与队列移除

- “所有歌曲”现在只汇总本地曲库和用户配置的 WebDAV，不再把播放过的在线曲目历史加入曲库；在线播放/搜索与播放队列仍可照常工作。收藏/歌单使用独立的在线曲目解析集，因此在线收藏不会丢失。
- 所有歌曲行新增始终可见的删除按钮，可按稳定 Track ID 移除曲库记录，不删除硬盘文件，并可通过提示条撤销；收藏和普通歌单行也有删除按钮，只从当前列表移除，不删除曲库文件；播放队列项保留移除按钮，当前播放项移除时切换至相邻项。
- 没有登记本地音乐路径时，曲库首帧直接为空，不再先展示旧的 Drift 扫描缓存；后台扫描仍负责清理过期索引。
- 保留用户当前 `music音源/` 目录和整理后的脚本原样；本轮只清理在线歌曲自动并入曲库的应用行为。
- 实现位置：`lib/features/library/library_pool.dart`（曲库来源）、`library_store.dart`（隐藏记录）、`library_views.dart`（移除与撤销 UI）、`lib/core/audio/player_engine.dart` / `player_providers.dart`（队列移除）、`lib/features/player/player_page.dart`（队列按钮）。
- 音源扫描修复：启动阶段等待音源登记完成；扫描程序目录和工作区的所有 `music音源` 候选并去重，不再因首个空目录导致漏扫。
- 验证：本轮修改后需重新执行 `flutter analyze`、`flutter test --reporter compact`，并重新构建 Windows Debug 产物。
- 限制：隐藏曲目记录保存在当前用户配置中；用户若要重新显示可用移除提示中的“撤销”，后续可增加统一管理隐藏曲目的设置入口。

## 本轮 0.1.0 beta 准备工作

- 清理无实现价值的旧播放器布局、旧紧凑播放器实现、空模块/空平台入口、过期玻璃画廊、遗留占位控件及播放设置页迁走的音乐库私有实现；保留现行播放页、紧凑播放器、曲库、音源/下载、WebDAV、主题与 Windows 功能。

- 在线曲目不再将音源返回的码率写入 `Track` 的 bitrate 覆盖值；在线只显示音质，真实本地码率继续来自文件媒体元数据。
- 修订旧 UI/码率测试预期，不删除功能测试；双语歌词用例验证原文与翻译沿同一时间轴合并。
- 更新 README、架构、目录结构、多平台/Windows 指南、歌词和玻璃专题、版本规则、协议清单及本交接页。
- 删除旧的个人命名 IDE 文件，并把测试临时目录/展示文案统一到 HoH 名称。

## 代码入口

| 区域 | 文件/目录 | 作用 |
|---|---|---|
| 应用启动 | `lib/main.dart`, `lib/app.dart` | Flutter 启动、MediaKit 初始化、应用根与 Windows 集成挂载 |
| 播放状态 | `lib/core/audio/player_engine.dart`, `player_providers.dart` | 唯一 MediaKit Player、曲目模型、播放状态/控制 |
| 本地曲库 | `lib/features/library/`, `lib/core/database/` | 文件夹扫描、列表、Drift 本地索引 |
| 在线来源 | `lib/core/source/`, `lib/features/source/` | LX 兼容 JS 沙箱、单活动音源、搜索/解析/下载 |
| 远端 WebDAV | `lib/core/remote/`, `lib/features/remote/` | 连接设置、客户端和页面 |
| 歌词 | `lib/features/player/lyrics/` | 解析、时间轴、摄影机词幕/滚动列表、逐词数据输入 |
| 主题/外观 | `lib/shared/theme/`, `lib/shared/widgets/widget_kit/` | 偏好、主题包、背景、玻璃组件 |
| Windows | `lib/platforms/windows/`, `windows/` | 窗口、托盘、快捷键、SMTC、桌面歌词和 runner |

依赖以 `pubspec.lock` 为准；新增、移除或复制第三方内容须更新[开源项目与协议清单](开源项目与协议清单.md)。

1. 在干净 Windows 用户环境解压/安装 Release 文件，验证首次启动、设置保存、退出和二次启动。
2. 实测本地音频播放/暂停/切歌、歌词暂停与翻译同步、桌面歌词锁定/拖动。

## 当前不支持/未实现

- Android、iOS、macOS、Linux、Android TV、Apple TV：缺少完整平台工程或未完成目标设备验收。
- 跨设备同步：只有待确认方案，尚无实现；移动端/TV 与 Home Assistant 属远期规划。
- 更多歌词视觉模式、频谱驱动动效：不属于当前交付能力，不要在 UI/文档中当作已实现功能。
