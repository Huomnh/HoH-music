# 音频输出通道

## 设计定义

播放设置里的“输出通道”按通用音乐播放器的含义实现为“系统音频输出设备路由”，不是左右声道混音器。这样可以复用当前项目已经使用的 media_kit 播放后端，并让 Windows、macOS、Linux、Android 和 iOS 按平台返回实际可用设备。

默认选项是“自动选择（系统默认）”。当系统返回设备列表时，界面还会展示设备描述，例如扬声器、耳机、蓝牙设备或虚拟音频设备。设备描述由操作系统和 media_kit 提供，不能在应用内可靠地硬编码。

## 数据流

1. `PlayerEngine` 暴露 media_kit 的 `audioDevice` 和 `audioDevices` 流，并封装 `setAudioDevice`。
2. `PlayerController` 将当前设备与可用设备列表放进 `PlayerUiState`，播放设置通过 Riverpod 订阅，不监听高频播放位置。
3. 用户选择设备后，`PlayerController.setAudioDevice` 立即调用底层播放器，同时把设备名称写入 `SharedPreferences` 的 `playback.audioDevice`。
4. 下次启动读取设备名称并尝试恢复；设备不存在或平台尚未完成枚举时仍保留自动选择，播放继续工作。

## 平台降级

- Windows / macOS / Linux / Android / iOS：由 media_kit 返回当前平台的设备名称和描述。
- Web、测试环境或原生音频后端不可用：只显示“自动选择（系统默认）”，不会因为设备枚举失败而阻止页面或播放逻辑。
- 当前版本不提供单声道、左声道、右声道混音。若未来需要声道混音，应单独增加 DSP/滤波层，不能把混音模式伪装成输出设备选择。
