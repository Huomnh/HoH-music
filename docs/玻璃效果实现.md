# 玻璃材质与背景绘制

普通主题的玻璃视觉以 `liquid_glass_plus`（Windows）或低强度原生 `BackdropFilter`（Android）实现。墨白/白墨极简主题不使用玻璃、折射、渐变或扫光，而由 `GlassPanel` 提供纯色平面和高对比边框。HoH 自有 widget/paint 只负责布局与内容隔离；可复用控件位于 `lib/shared/widgets/widget_kit/`，参数与性能偏好位于 `lib/shared/theme/`。

外观设置中的玻璃参数直接对应插件配置：玻璃厚度 `thickness`、磨砂强度
`frostIntensity`、折射率 `refractiveIndex`、色散 `chromaticAberration`、光照角度
`lightAngle`、光照强度 `lightIntensity`、环境光 `ambientStrength`、背景饱和度倍率
`saturation` 和 Skia 回退折射 `FakeGlassConfigs.refraction`。这些值通过
`SharedPreferences` 保存，并随 `.hohtheme` 主题包导入导出。

正式版首次启动的高端档位默认直接采用当前外观设置：模糊 16、填充透明度 0%、
玻璃饱和度 0.08、玻璃色调 0.08、厚度 6.6359、磨砂 0.4839、折射率 1.0311、
色散 0.0030、光照角 1.426 弧度、光照强度 0.3779、环境光 0.0933、背景饱和度
1.4211、Skia 回退折射 4.0829；动画开启、边框扫光关闭、高光强度为 1。没有保存
用户覆盖时才使用这组值，已有用户覆盖仍然优先。

## 当前组件

| 文件 | 职责 |
|---|---|
| `glass_surface.dart` | 组合背景模糊、材质、边框和内容的容器 |
| `glass_blur.dart` | 旧版玻璃兼容组件；主面板不再直接使用 |
| `glass_material.dart` | 玻璃底色、细节纹理和边缘高光 |
| `glass_border.dart` | 边缘描边、高光和渐变文字/动效 |
| `glass_panel.dart` | 按平台/主题组合液态玻璃、低强度原生模糊或黑白平面材质 |
| `liquid_glass_settings.dart` | 主界面与试用页共用的插件参数桥接；Windows Fake Glass 稳定策略 |
| `blur_config_scope.dart` | 将性能/模糊参数下发给子树 |
| `neon_background.dart` / `background_scenes.dart` | 背景光场与内置背景绘制 |
| `performance_tier.dart` | 渲染档位参数和偏好持久化 |

背景必须先绘制在玻璃下方。主面板不再额外套 HoH 自有 `BackdropFilter`，避免与插件重复采样。边框高光使用 `IgnorePointer`，不能拦截内部按钮点击；UI 测试需验证这一点。

## 背景和性能

当前内置动态背景仅保留液态流光；墨白极简/白墨极简是单色静态背景，静态自定义图片仍可用。动态效果由 Flutter `CustomPainter` 绘制，不是预渲染视频。液态流光的内置定义带 `followTheme: true`，会从当前专辑封面同时提取彩色簇和黑/灰/白中性簇：彩色簇使用面积幂次压缩评分，降低大面积单色对辅助色的支配；中性簇保留封面的黑白视觉基调。`AppAccent` 将可读 UI 强调色与背景使用的原始 `sceneColors` 分离，再在约 820ms 内平滑驱动主题与光场；取色失败时保持当前主题，不影响播放。外观设置的 RGB 取色器采用色相环和饱和度/明度方块，黑、白、灰可以直接选择。旧主题包若包含已移除的暖霞流光、墨潮折影或彩虹甜心定义，会回退为液态流光。

高斯模糊、阴影和持续动画都有 GPU 成本。主背景光场以约 8.3fps 更新，保留 28 秒缓慢漂移周期；边框扫光共享一个约 16.7fps 时钟，保留 14 秒一圈。应用进入暂停状态时两个时钟停止；背景还受 `TickerMode` 和动效总开关控制，无面板订阅时边框时钟也停止。页面缩略图不启动持续动画；背景、玻璃内容和扫光继续由独立 `RepaintBoundary` 隔离。此优化降低重绘频率但不改玻璃材质参数与动效周期，目标设备上的 GPU 百分比仍需实机测量。

## liquid_glass_plus 全局玻璃层

`lib/shared/widgets/widget_kit/glass_panel.dart` 的所有 `GlassPanel` 均使用
`LiquidGlass.withOwnLayer`、`LiquidRoundedSuperellipse` 和
`buildHohLiquidGlassSettings`。这样播放页、曲库、搜索、设置、下载和 WebDAV 等页面
与外观设置试用面板共享同一套液态玻璃参数。

Windows 默认强制 `FakeGlassConfigs.forceEnabled`：这是插件官方的 Skia 回退路径，
用于规避不同 Windows Flutter 渲染器对 shader filter 支持不一致造成的背景反转。玻璃
色固定为低透明度白色，保持亮色传输混合；用户仍可通过厚度、磨砂、折射率、色散、光照
和 Skia 回退折射调节效果。边框流动高光不是玻璃材质本身，只是独立装饰层。

歌单传输与玻璃主题解耦，位于 `lib/features/library/playlist_transfer.dart`；
`.hohplaylist` 是独立的版本化 JSON 文件，不包含玻璃参数或临时播放地址。
