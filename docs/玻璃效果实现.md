# 玻璃材质与背景绘制

玻璃视觉由 Flutter 原生 widget/paint 实现，不依赖单独的玻璃 UI 插件。可复用控件位于 `lib/shared/widgets/widget_kit/`，参数与性能偏好位于 `lib/shared/theme/`。

## 当前组件

| 文件 | 职责 |
|---|---|
| `glass_surface.dart` | 组合背景模糊、材质、边框和内容的容器 |
| `glass_blur.dart` | `BackdropFilter` 模糊与圆角裁剪 |
| `glass_material.dart` | 玻璃底色、细节纹理和边缘高光 |
| `glass_border.dart` | 边缘描边、高光和渐变文字/动效 |
| `glass_panel.dart` | 页面面板布局组件 |
| `blur_config_scope.dart` | 将性能/模糊参数下发给子树 |
| `neon_background.dart` / `background_scenes.dart` | 背景光场与内置背景绘制 |
| `performance_tier.dart` | 渲染档位参数和偏好持久化 |

背景模糊使用 `BackdropFilter`，所以必须有已绘制背景位于玻璃下方。装饰层需遵守命中测试要求，不能拦截内部按钮的点击；更新玻璃结构时应保留 `interactive` 路径并在 UI 测试中验证。

## 背景和性能

当前内置动态背景为液态流光；静态自定义图片仍可用。动态效果由 Flutter 绘制，不是预渲染视频。主题包可携带动态背景定义和自定义图片资源；导入后不依赖用户原始图片路径。

高斯模糊、阴影和持续动画都有 GPU 成本。页面缩略图不应启动持续动画；无交互时应避免无界重绘；性能设置的参数应对应真实渲染行为，不保留失效的选项。
