# 多平台构建可行性评估

> 更新：2026-10-03。结论依据当前仓库平台目录、依赖和本轮验证；不是对未来兼容性的保证。

## 当前支持边界

| 平台 | 工程目录 | 当前结论 |
|---|---|---|
| Windows Desktop | `windows/` | 当前唯一工程化和正式发布目标；Flutter analyze、测试、Release 构建和 Windows 安装器本轮均已验收通过。干净用户环境仍需单独验证。 |
| Android | `android/` | 已加入 runner 与移动端 UI 预览，Android 版本从 `0.0.1` 起算；本机没有 Android SDK，尚未完成 APK 构建和真机验收。 |
| iOS | 不存在 | 未实现；构建还需要 macOS/Xcode。 |
| macOS | 不存在 | 未实现；构建需要 macOS/Xcode。 |
| Linux | 不存在 | 未实现、未构建、未验收。 |
| Android TV / Apple TV | 不存在 | 未实现；除平台工程外还需遥控器焦点和大屏适配。 |
| Web | 不存在 | 不属于当前产品目标；桌面系统集成和音源脚本能力须另行评估。 |

“使用 Flutter”仅说明业务层有复用基础，不等于插件、文件权限、后台播放、媒体会话、窗口和打包都跨平台可用。

## 共享代码与平台专属能力

适合共享：曲目/队列状态、歌词解析与时间轴、主题数据和绘制、播放页侧栏/底部控制布局、主页面与紧凑播放器的内容过渡、队列安全区布局、歌词页/桌面歌词快捷入口状态、下载任务状态机、音源脚本数据契约和进度条的视觉 widget。播放页控制区、入口按钮、页面过渡、队列布局和进度条动画已经使用纯 Flutter provider/widget 状态，不依赖 Windows API；移动端/TV 只需处理屏幕尺寸、触控或遥控器焦点。紧凑播放器的窗口固定尺寸、置顶和四角定位、单实例互斥、托盘及退出清理仍属于 Windows 外壳能力；其他平台可复用控制内容和动画，再由平台窗口适配器决定承载方式。桌面歌词按钮在非 Windows 平台可以保留共享状态并由平台能力适配器决定是否显示或提供替代歌词页入口。Windows 为规避 Flutter 3.47.5 accessibility bridge 的 AXTree 崩溃暂时在根组件隔离 Flutter 语义树，移动端/Web 不应复制这一限制。

需要逐端适配并实机验证：音频焦点及后台播放、媒体控制通知、目录选择/权限、后台下载、窗口和桌面歌词、全局快捷键、TV 焦点系统。

当前 Windows 实现集中在 `lib/platforms/windows/`；Android 移动壳层集中在 `lib/features/mobile/mobile_app_shell.dart`，应用组装通过平台判断选择移动或桌面入口。部分应用组装代码仍直接挂载 Windows 能力，进入更深的 Android 能力开发前，要把这些调用边界抽成 capability adapter，并提供不支持平台的无操作或 Flutter fallback。

## 当前工具链与验证

- 本机已使用 Flutter 3.47.5 stable / Dart 3.13.4。
- Windows 构建还需要 Visual Studio 的 C++ Desktop workload；`smtc_windows` 使用 Rust 构建桥接，缺少所需工具链会阻断 Windows build。
- 本轮 `flutter analyze --no-pub` 通过。
- 本轮 `flutter test --reporter compact`：84 项通过。
- 本轮 `flutter build windows --release`：正式版构建通过；Inno Setup 安装器编译和自选目录安装/卸载冒烟测试通过。干净机器安装/启动与实际媒体验收仍需保留为发布后的验收项。
- 本轮 `flutter build apk --debug`：未进入 Gradle 构建，执行环境报告 `No Android SDK found`；`flutter devices` 未发现 Android 设备。Dart 分析与现有 91 项测试通过。

## 新平台进入条件

1. 生成并维护平台 runner、签名与 CI 构建。
2. 审核 `pubspec.yaml` 每个插件对目标平台的支持矩阵，替换 Windows-only 能力。
3. 实现文件权限、后台音频、系统媒体会话和下载生命周期。
4. 在真实设备验收启动/关闭、播放/暂停、切歌、歌词翻译同步、导入/下载、设置保存。
5. 同步更新平台矩阵、构建指南、协议清单与交接记录。

Android 当前的具体命令和限制见 [Android 预览指南](Android预览指南.md)。

跨端同步暂缓实施，技术选择仍待用户确认，见 [跨端同步技术方案](跨端同步技术方案.md)。
